# Icona SpeseProfit

Sorgenti dal kit approvato Blu notte e champagne: portafoglio SP, foglie e punto sulla chiusura. Nessun simbolo ±. Gli SVG sono i sorgenti, i PNG sono usati da Expo. app.config.js conserva i riferimenti anche dopo prebuild. Le risorse native correnti includono fallback WebP, adaptive icon Android 8+ e monochrome Android 13+. Foreground e monochrome hanno identico posizionamento nella zona sicura.

Le icone launcher non modificano schermate, dati o crittografia. Gli asset vengono inclusi nella build successiva. Script riproducibile: scripts/generate-brand-icons.cjs, con sharp fornito da SHARP_MODULE oppure installato nell’ambiente di esecuzione; nessuna dipendenza aggiunta all’app.
